# База склада тортов (SQLite)

Файл базы живёт на iMac рядом с API. Схема построена по реальным заявкам
клиента (фото от 17.10.2026 в `../source/`): **маршрут → заказчик → точка
разгрузки → заявка → сводная заявка маршрута (лист сборки) → отгрузка →
возвраты; оборотные ящики числятся за водителем**.

| Файл | Что внутри |
|---|---|
| `schema.sql` | Таблицы, ограничения, триггеры, представления |
| `seed.sql` | Начальные данные (сгенерирован `build_seed.py`, руками не править) |
| `build_seed.py` | Генератор `seed.sql`: ассортимент из `api/bots/cake.py`, точки и заявки с фото |
| `check_db.py` | Собирает базу с нуля и проверяет её |
| `queries.sql` | Частые запросы: сводная, остатки, нехватка, ящики |
| `import_places.py` | Бланк «Карта склада» и его загрузка в `places.csv` |
| `pick_sheet.py` | Лист сборки по кругу: заявка или весь маршрут, HTML + PDF |

## Таблицы

```
categories ─< products ─────────────┐
routes ─< points >─ customers       │
             │                      │
routes ─< orders >─ points          │
             ├─< order_lines >──────┤
             └─< order_returns >────┤
route_sheets ─< orders (sheet_id)   │
stock_moves  >─ products, orders, route_sheets   (журнал, только добавление)
tara_moves   >─ tara_types, staff (водитель), route_sheets (журнал, только добавление)
staff ─< shifts;  staff ─< route_sheets (сборщик, водитель)
```

- **products** — 94 позиции, 5 категорий, вес единицы, отметка «весовой»;
  артикул, срок годности, минимальный остаток — пустые, заполнит клиент.
- **routes / customers / points** — 2 маршрута, 8 заказчиков, 24 точки
  разгрузки (адрес, номер магазина сети, окно доставки).
- **orders / order_lines** — заявка с номером клиента; в строке кол-во,
  грузовые места (40 эклеров по 75 г = 4 места) и признак бонуса.
- **route_sheets** — сводная маршрута на дату: «Сборку осуществил»,
  количество ящиков и стопок, водитель, статусы сборки и отгрузки.
- **stock_moves** — журнал движений: остаток = сумма. Триггеры запрещают
  правку и удаление: ошибка исправляется корректировкой (`adjust`).
- **tara_moves** — оборотные ящики за водителем: `out` выдали (+), `back`
  вернул (−), `writeoff` утерял (−, долг списан). Вернуть больше, чем на
  руках, и выдать ящики не водителю — нельзя (триггеры). Стопки — не тара,
  а количество для погрузки в листе сборки.

Представления: `v_stock` (остатки), `v_order_totals` (итоги заявки как в
накладной), `v_route_summary` (сводная по маршруту), `v_route_shortage`
(чего не хватает), `v_driver_tara` (ящики по водителям: выдано, вернул,
утерял, долг), `v_sheet_tara` (ящики по рейсу), `v_tara_stock` (на складе).

## Сборка по кругу

Ящики с тортами стоят по периметру склада, у каждого товара одно место
(расставляет дневная смена). Лист сборки печатается **в порядке обхода
против часовой стрелки от двери** — один круг без беготни.

1. **Карта склада** — один раз: бланк `../karta-sklada.xlsx`, вписать номер
   места для каждого товара (жёлтая колонка). Загрузить:
   `python3 cake-warehouse/db/import_places.py karta-sklada.xlsx` → `places.csv`.
   Переставили торт — поменять номер в бланке и загрузить снова.
2. **Лист сборки:**
   - одна заявка: `python3 cake-warehouse/db/pick_sheet.py --order 1103609`
   - весь маршрут за один круг (со следующей недели):
     `python3 cake-warehouse/db/pick_sheet.py --route "Маршрут 3" --date 2026-10-17`
     — общее количество по каждому месту и раскладка по заявкам
     («№3609: 2»), за ним листы каждой заявки для сверки на середине.

Получается HTML и PDF в `out/` (A4, как бумажный лист: ✓, Место,
Наименование, Кол-во, Мест, Вес, Итого, подписи «Сборку осуществил»,
ящики, стопки). Товары без места — в конце листа с пометкой. Бонус
пишется словом, чтобы «2б» не прочитали как «26».

## Команды

```bash
python3 cake-warehouse/db/build_seed.py        # пересобрать seed.sql
python3 cake-warehouse/db/check_db.py          # проверить (временная база)
python3 cake-warehouse/db/check_db.py cake.db  # создать файл базы (не перезаписывает)

# или напрямую:
sqlite3 cake.db < cake-warehouse/db/schema.sql
sqlite3 cake.db < cake-warehouse/db/seed.sql
sqlite3 -header -column cake.db < cake-warehouse/db/queries.sql
```

На iMac база лежит в `TGS_DATA_DIR` API (см. `api/README.md`). Бэкап —
`sqlite3 cake.db ".backup backup/cake-$(date +%F).db"`. Посмотреть глазами —
DB Browser for SQLite (`brew install --cask db-browser-for-sqlite`).
