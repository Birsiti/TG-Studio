# Сборка по кругу

**В приложении:** вкладка «Сборка» у кладовщика — лист с галочками на
телефоне, по заявке или весь маршрут, места задаются там же («Места на
складе»). Как пользоваться — `user-guide.md`. Ниже — печатный лист (PDF)
и загрузка карты склада из Excel для SQL-базы `db/`.

Ящики с тортами стоят по периметру склада, у каждого торта одно место
(расставляет дневная смена). Заказы собираются на середине. Лист сборки
печатается **в порядке обхода по часовой стрелке от двери** — один
круг без беготни.

## Карта склада (один раз)

1. Откройте бланк `cake-warehouse/karta-sklada.xlsx`.
2. Встаньте у двери, идите по часовой стрелке. Первое место — 1,
   следующее — 2 и т.д. Впишите номер в жёлтую колонку у каждого торта.
   - Несколько тортов на одном месте — один номер.
   - Торта нет на складе — оставьте пусто: он будет в конце листа.
3. Загрузите:
   ```bash
   python3 cake-warehouse/db/import_places.py karta-sklada.xlsx
   ```
   Скрипт проверит бланк (числа, лишние строки) и создаст `db/places.csv`.

Переставили торт — поменяйте номер в бланке и загрузите снова.

## Лист сборки

**Одна заявка** (сейчас):
```bash
python3 cake-warehouse/db/pick_sheet.py --order 1103609
```

**Весь маршрут за один круг** (со следующей недели):
```bash
python3 cake-warehouse/db/pick_sheet.py --route "Маршрут 3" --date 2026-10-17
```
Первый лист — общее количество по каждому месту и раскладка по заявкам
(`№3609: 2 · №3342: 1`): берём всё за один круг, на середине раскладываем.
Дальше — листы каждой заявки для сверки.

Результат — HTML и PDF в `cake-warehouse/db/out/` (A4): ✓, Место,
Наименование, Кол-во, Мест, Вес, Итого, внизу «Сборку осуществил (ФИО)»,
ящики, стопки.

- Без места — в конце листа с пометкой, ничего не теряется.
- Бонус пишется словом («2 бонус»), чтобы «2б» не прочитали как «26».
- Итоги совпадают с накладной клиента (проверяется `check_db.py`).

## Откуда берутся заявки

Сейчас — из фото накладных: их переносят в `db/build_seed.py` и
собирают базу. Если программа клиента умеет выгрузку в Excel/CSV —
лучше загружать её. Следующий шаг — ввод заявок прямо в приложении,
тогда лист с галочками будет у кладовщика в телефоне.
