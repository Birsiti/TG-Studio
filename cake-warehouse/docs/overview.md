# Обзор

## Что делает система

- **Остатки** — сколько каждого торта на складе, что заканчивается, что в пути.
- **Приход** — что пришло с производства.
- **Рейсы** — кладовщик собирает рейс (торты + ящики) на водителя,
  отгружает, водитель после развоза сдаёт отчёт о возврате, кладовщик
  принимает рейс.
- **Ящики** — оборотная тара за водителями: выдано, вернул, утерял, долг.
- **Журнал** — каждое движение торта с датой, выгрузка в CSV.
- **Смены и справочники** — кто работает, ассортимент, люди, тара.
- **Бот** — кнопки входа по ролям, уведомления о рейсах, утренняя сводка.
- **Сборка по кругу** — лист сборки заявки или маршрута в порядке обхода
  склада против часовой стрелки (см. [picking.md](picking.md)).

## Роли

| Роль | Экран | Что делает |
|---|---|---|
| Кладовщик | `sklad.html` | Приход, пересчёт, списание, сборка заявок по кругу, рейсы, приёмка, ящики, журнал |
| Водитель | `driver.html` | Видит свои рейсы и долг по ящикам, сдаёт отчёт о возврате |
| Руководитель | `admin.html` | Сводка, смены, справочники; получает утреннюю сводку в боте |

Роль определяется по Telegram id: руководители — в настройке
`TGS_CAKE_ADMINS`, остальные — в справочнике «Люди».

## Как идёт товар

```
Цех ──приход──▶ СКЛАД ──сборка рейса──▶ рейс (черновик, остаток не трогает)
                  ▲                         │ отгрузка: торты списаны,
                  │                         │ ящики записаны на водителя
                  │                         ▼
                  │                  водитель развозит
                  │                         │ отчёт: что везёт обратно
                  │                         ▼
                  └──годный возврат── приёмка рейса: брак фиксируется,
                                      ящики сняты с долга водителя
```

Списание (помят, истёк срок) и пересчёт (инвентаризация) — отдельные
записи журнала. Остаток = сумма всех записей по товару.

## Из чего состоит

```
Telegram ──▶ бот cake-bot (iMac) ──▶ кнопки Web App ──▶ страницы на GitHub Pages
                │                                         sklad / driver / admin.html
                │ служебный ключ                                 │ запросы с подписью Telegram
                ▼                                                ▼
           API склада: api/bots/cake/ (iMac, FastAPI) ◀──────────┘
                │
                ▼
           SQLite cake.db (iMac)
```

| Часть | Где | Что |
|---|---|---|
| Страницы Mini App | `cake-warehouse/*.html`, `js/`, `brand.css` | Интерфейс для телефона, светлая и тёмная тема |
| Демо-режим | `mock.js`, `mock-data.js`, `mock-orders.js`, `mock-picking.js` | Если сервер недоступен — работает на данных в браузере |
| API | `api/bots/cake/` | Учёт, проверки, доступ, демо-данные |
| Бот | `cake-bot/` | /start, /id, уведомления, утренняя сводка |
| База под маршруты | `cake-warehouse/db/` | SQL-схема по реальным заявкам, листы сборки по кругу |

## Защита

- Без подписи Telegram от вашего бота сервер не ответит (если задан токен).
- Пускает только руководителей из настройки и сотрудников из справочника.
- Журнал движений нельзя изменить или удалить.
- Нельзя отгрузить больше, чем есть; вернуть больше, чем уехало;
  принять ящиков больше, чем на руках.
