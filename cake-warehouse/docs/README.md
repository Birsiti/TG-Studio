# ТОРТОВОЗ — документация

Учёт склада тортов с развозом: остатки, приход, рейсы водителей, оборотные
ящики, сборка заказов по кругу склада. Telegram Mini App + бот + API на iMac.

| Документ | Для кого | Что внутри |
|---|---|---|
| [Обзор](overview.md) | все | Что умеет система, роли, как идёт товар, из чего состоит |
| [Инструкция](user-guide.md) | кладовщик, водитель, руководитель | Как работать с каждым экраном, по шагам |
| [Установка на iMac](setup-imac.md) | кто запускает | API, бот, переменные, проверка, бэкап, обновление, смена токена |
| [Сборка по кругу](picking.md) | кладовщик, руководитель | Карта склада и листы сборки заявки и маршрута |
| [API](api.md) | разработчик | Все действия сервера, параметры, ответы, ошибки |
| [База данных](database.md) | разработчик | Таблицы, журналы, отчёты, схема под маршруты и заявки |
| [Разработка](development.md) | разработчик | Структура файлов, тесты, как добавить функцию |

Коротко о главном:

- **Остаток не хранится, а считается** из журнала движений — задним
  числом поправить нельзя, ошибка исправляется пересчётом.
- **Ящики числятся за водителем**: выдали при отгрузке → сдал при
  приёмке → разница = долг.
- **Всё хранится на iMac**: база SQLite и состояние бота. Токен бота и
  ключи — только в настройках на iMac, в репозитории их нет.
