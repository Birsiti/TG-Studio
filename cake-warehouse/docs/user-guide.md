# Инструкция

Вход — через бота: `/start` показывает кнопки вашей роли. Если доступа
нет, бот покажет ваш Telegram id — передайте его руководителю.
Тема (светлая/тёмная) — кнопка-солнышко вверху справа.

## Кладовщик (`sklad.html`)

Внизу пять вкладок: Остатки, Приход, Рейсы, Ящики, Журнал.

### Остатки
- Поиск по названию, фильтр по категории и «Есть на складе».
- Красное число и «мало» — остаток ниже минимального.
- Нажмите на торт:
  - **Пересчитать** — впишите, сколько насчитали; разница запишется в журнал.
  - **Списать** — сколько и причина (помят, истёк срок).

### Приход
1. Дата и «Откуда» (по умолчанию сегодня).
2. Найдите торт поиском, впишите количество. Внизу видно, сколько всего.
3. «Оприходовать».

### Сборка
Заявки точек на дату и лист с галочками **в порядке обхода склада** —
по часовой стрелке от двери (номер места — в цветном квадрате слева).
1. Сверху выберите дату и маршрут.
2. Откройте заявку → берите торты сверху вниз и отмечайте строку тапом.
   Отметки видят все: можно собирать вдвоём.
3. «Собрано» → количество ящиков (обязательно, нет ящиков — 0). Строки не отмечали —
   приложение спросит «Всё уже собрано?» и отметит все разом. Кто собрал,
   не спрашиваем: собирает вся смена. Руководителю придёт сообщение в боте.
4. Ошиблись — «Вернуть в сборку».

**Весь маршрут за один круг** (со следующей недели): выберите маршрут →
«Весь маршрут». Лист показывает, сколько взять с каждого места и как
разложить по заявкам (`№3609: 2 · №3342: 1`).

**Отгрузить маршрут:** когда все заявки маршрута собраны — «Весь маршрут» →
«Отгрузить маршрут водителю» → водитель (сверху — кто на смене) → «Создать
рейс». Появится рейс на сборке с суммой тортов и ящиков по заявкам; дальше
как обычно на вкладке «Рейсы» — «Отгрузить». Отменили рейс — заявки снова
можно отгрузить.

**Новая заявка:** «Новая заявка» → номер, дата, точка, количества. Бонус
из накладной пишите в комментарий (бонусные строки из заявок с фото
сохраняются).

### Рейсы
**Собрать рейс:** «Новый рейс» → дата → город → водитель (сверху — кто на
смене) → количество тортов (поиск, «Только выбранные») → «Ящики водителю»
→ «Сохранить». Остаток пока не меняется — это сборка.

**Отгрузить:** откройте рейс → «Отгрузить» → подтвердить. Торты
списываются со склада, ящики записываются на водителя, водитель получает
уведомление в боте.

**Принять:** когда водитель сдал отчёт, рейс появится в «Ждут приёмки»,
а вам придёт сообщение. Откройте → «Принять рейс». Поля заполнены по
отчёту водителя — сверьте:
- **Годные** — вернутся на остаток;
- **Брак** — только отмечается (он уже списан отгрузкой);
- **Ящики вернул** — снимаются с долга водителя.

Рейс на сборке можно изменить или отменить. Отгруженный — нет.

### Ящики
- Сверху: на складе, у водителей, утеряно.
- Список водителей: выдано · вернул, справа — долг.
- Нажмите на водителя — история и запись вне рейса:
  - **Вернул** — довёз ящики позже;
  - **Выдали** — без рейса;
  - **Утерял** — потерял или сломал: долг списывается, ящиков в обороте меньше.

### Журнал
Все движения тортов за сегодня / 7 / 30 дней, фильтр по типу,
«Выгрузить CSV» — откроется в Excel.

## Водитель (`driver.html`)

- **Текущие рейсы** и **Последние**; плашка «Ящиков на руках» — ваш долг.
- **Выезд:** откройте рейс → впишите спидометр → «Выезжаю».
- После развоза: откройте рейс → «Сдать рейс» → сколько тортов везёте
  обратно (целые / брак), сколько ящиков сдаёте, спидометр сейчас
  (обязательно), комментарий →
  «Отправить на склад». Кладовщик получит уведомление.
- Отчёт можно исправить, пока склад не принял рейс.
- Бот пишет: «рейс отгружен вам» (состав и ящики), «рейс принят складом».

**Заявка по фото.** «+ Новая заявка» → номер, точка → «Фото или файл
заявки» (камера, галерея или PDF) → «Сохранить». Торты можно не вносить —
собирают по фото. Чтобы отгрузить маршрут рейсом, торты всё же нужно внести
(«Изменить»): рейс списывает остаток по строкам. Фото к любой заявке —
кнопка «Фото или файл заявки» в её окне; тап по фото — на весь экран,
там же «Удалить фото».

**Отметить все собранными** — кнопка под списком заявок: для тех, что
собрали по бумаге и не отмечали в приложении (с фильтром маршрута — только
этот маршрут).

## Руководитель (`admin.html`)

- **Сводка**: на складе, отгружено сегодня и за 14 дней, рейсы в пути и
  на приёмке, ящики у водителей, возвраты, списания, график по дням,
  города, ходовые торты. «Мало на складе» — сверху.
- **Водители** (7 дней / 30 дней / 3 месяца): по каждому — рейсы и точки,
  пробег по спидометру и в среднем на рейс, **км между рейсами** (выезд
  минус прошлый возврат — поездки вне рейсов), рейсы без спидометра,
  отгружено, возвраты (целые / брак / %), **недостача** (в отчёте водитель
  заявил больше, чем принял склад), ящики на руках. Красным — то, на что
  стоит посмотреть. Фильтр «Все / Свои / Наёмные» — отдельно машины фирмы
  и наёмных перевозчиков.
- **Смены**: выберите день, включите тех, кто работает. Водители на смене
  первыми предлагаются при сборке рейса.
- **Справочники**: торты (категория, вес, срок, минимальный остаток),
  города, люди, тара. У водителя — **чья машина**: своя (фирмы) или
  наёмный, у наёмного — фирма-перевозчик; в рейсах он помечен «наём.».
  Кнопка **«Кто заходит в бота»** (в «Людях»): все, кто писал боту или
  открывал склад, когда и куда; у кого нет доступа — «+» добавит его в
  «Люди» с готовым id. О каждом новом человеке бот пишет руководителю в личку.
  У человека впишите **Telegram id** — без него он не
  войдёт в рабочем режиме. Скрытые позиции не предлагаются, но история
  остаётся.
- **Бот** каждое утро в 7:00 присылает сводку за вчера.
- **Загрузка из файла.** «Приход» → «Загрузить приход из файла»,
  «Сборка» → «Загрузить заявки из файла»: Excel или CSV из 1С или
  таблицы. Нужны колонки «Наименование» и «Кол-во»; для заявок ещё
  «Заказчик», «Адрес», «Маршрут», «№ заявки» (дата и бонус — по желанию).
  Торт узнаётся по названию и весу; что не узналось — выберите из списка.
  «Пример файла» — образец.
- **Логист** (роль в «Людях»): заявки по маршрутам, рейсы, водители, ящики.
  Рейс водителю: «Рейсы» → «Новый рейс» → дата, водитель → отметьте заявки
  по порядку объезда (номер у заявки — порядок). Торты считаются сами.
  Водитель в «Мои рейсы» видит точки с адресами и кнопки на карту.
- **Показать приложение кому-то** — напишите боту `/demo`: до конца дня
  любой, кто нажмёт /start, увидит демо со всеми экранами (данные
  примерные, только в его телефоне). `/demo 3` — на три дня, `/demo off` —
  закрыть.

## Частые вопросы

**Ошибся в приходе.** Пересчитайте торт на вкладке «Остатки» — разница
запишется. Удалить запись нельзя: так учёт остаётся честным.

**«Не хватает: …» при отгрузке.** На складе меньше, чем в рейсе.
Измените рейс или оприходуйте недостающее.

**«Демо-режим» вверху.** Сервер недоступен, данные только в этом
телефоне. Проверьте интернет и iMac.

**«Откройте приложение из бота».** Страницу открыли по ссылке в браузере —
откройте кнопкой в боте.
