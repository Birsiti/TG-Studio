## Решения клиента (не переспрашивать)

- Обход склада — **по часовой стрелке** от двери. Места 1…65 сняты по фото
  (`db/places-photos.csv`), в базу поставлены один раз (meta `places_v1`),
  дальше в базе последнее сохранение из приложения.
- **Вес — как на упаковке.** Разный вес одного торта — разные товары.
  Вес обязателен у каждого товара.
- **Шт в 1 грузовом месте** (`perBox`): «10 шт в коробке — количество 10,
  мест 1». Места в заявке = Σ ceil((кол-во+бонус)/perBox).
- **Кто собрал — не спрашиваем**: собирает вся смена. **Количество ящиков —
  обязательно** при «Собрано» (0, если нет): ящики уходят на водителя.
- «Собрано» без галочек → вопрос «Всё уже собрано?» → отмечаются все строки.
- Окно «Места на складе» — по номерам мест, без места — в конце.
- LEADTEX для этого бота не используется: бот живёт на iMac, как такси.

## Фото заявок и «все собраны» (17.10)

К заявке — фото или PDF (`order_files`, файлы на диске iMac в
`TGS_DATA_DIR/cake-files/`). Заявка может быть «по фото» без строк; для

остальные боты — 64 КБ.

## Кнопка «Открыть» и главная (18.10)

Под сообщениями бота кнопок больше нет. Бот при запуске ставит кнопку
«Открыть» внизу чата (`setChatMenuButton`, одна для всех) → `index.html`:
три входа (руководитель / кладовщик / водитель), в рабочем режиме сотрудник
сразу попадает на свой экран. Там же бот ставит описание для пустого чата и
профиля (`setMyDescription`, `setMyShortDescription`). Кнопку «Открыть» в
профиле и списке чатов (Main Mini App) включает Денис в @BotFather: Bot
Settings → Configure Mini App → Enable, ссылка
`https://birsiti.github.io/TG-Studio/cake-warehouse/index.html`.

## Гостевой вход для показа (18.10)

Руководитель пишет боту `/demo` — до конца дня любой, кто нажмёт /start,
получает приветствие-презентацию и все три кнопки (как у руководителя).
Без туннеля приложение у гостя в демо: данные примерные и только в его
телефоне, рабочая база не видна. О каждом новом госте — «🎂 Гость открыл
демо». `/demo 3` — на 3 дня, `/demo off` — закрыть (`demoUntil` в
`cake-bot/data/state.json`). Плашка в приложении: «Демо-версия: данные
примерные…» (раньше «сервер недоступен» — пугало на показе).

## Как обновляется iMac

Обновление делает отдельная сессия Claude Code на iMac (с ней общаются
через сообщения между сессиями). Каждый раз одно и то же:
копия базы в `~/backup/cake-<дата>-before<коммит>.db` → `git pull` →
прогрев `(cd api && .venv/bin/python -c "import server")` → `kickstart`
API → ждать `/health` → если менялся бот: `npm install` и `kickstart`
бота → `npm run check`. Plist-файлы и `install.sh` без прямого согласия
Дениса не трогать.
